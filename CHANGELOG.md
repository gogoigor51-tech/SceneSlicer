# История / Release history

## 1.2.2f · 20 ноября / November 2026

Первый публичный выпуск с установщиком Windows x64 и подписанными обновлениями из программы. Раздельная очистка кеша с подтверждением, сохранение ручных правок, поиск по выбранным лицам-образцам, удаление нескольких персонажей, исправление OP/ED и опциональная склейка. Исправлены категории сцен и плашки в результатах поиска RU/EN.

First public release with a Windows x64 installer and signed in-app updates. Confirmed scoped cache cleanup preserving manual edits, reviewed face-exemplar search, bulk character deletion, corrected OP/ED detection and optional reversible joining, and RU/EN result labels.

## 1.2.1f / 1.2 / 1.1

Предыдущие доработки: назначение клипов нескольким персонажам, объединение имён, безопасное перетаскивание, цветокоррекция, выделение участка музыки и экспорт маркеров/аудио в After Effects, сборка релиза, прокси и уведомления. Подробная история сохранена в приложении.

Earlier work includes multi-character assignment and merging, clip dragging, colour grading, music-range selection and After Effects markers/audio, release building, proxies and notifications. The detailed history is retained in the app.
